## 【文献】NeurIPS 2018「Depth-Limited Solving for Imperfect-Information Games」（Brown/Sandholm/Amos，Modicum 那篇）

用户提供 PDF（`Downloads/NeurIPS-2018-depth-limited-solving-for-imperfect..pdf`）→ 已通读并整理进
`文献调研_可借鉴方案.md` **§九**。

**核心（可借鉴）**：隐信息游戏「状态无唯一价值」——叶子只填一个值 = 暗中假设对手打法固定；
解法 **多值状态**：让对手在深度限制处从 N 个策略里选（每叶子一个 N 维向量），我们**对 N 种都稳**。
N 小就够（翻前 10 / 翻后 4），复杂度对 N 线性。

**★★ 命中我们的实验（Table 1）**：**「叶子一个值」的实时精修（naïve）≈ 打不过它想精修的蓝图**
（vs Baby T8：蓝图 −57 → naïve −10 → 多值 +6）。**≈ 我们「出口链精修打不过 v50」** ——
因为我们的决策层就是「一个 `eq` + 一个 `range_pct`」= 单值精修。**这是 §8.7（KL 锚）之外第二个更硬的依据。**

**建议**（均未实施）：① 把 `range_pct` 换成 **4 个对手元策略**（现状/偏弃/偏跟/偏加），动作取最坏情况最好

### 追问澄清：`eq` 到底依赖什么（读代码确认）
- **两处调用点**（`strategy.py:2438` 与 `4345`）**都只传 `opp_range_pct=<标量>`，都没传 `opp_weights`** ⇒ 实际范围模型**永远是单一标量**（combo 级权重接口建好了但从未接线）。

### 追问 2：「计算对手只靠动作、不看数值」——核查结论
**对"对手手牌范围/eq"这条线：完全成立。** `_opp_range_pct` 的全部输入是 `eff_vpip()` / `opp_raised_preflop` / `eff_bet_freq()` / `street_raises`（**纯计数**），**没有任何金额**。
⇒ 机械后果：对手 **min-bet** 与 **pot-bet** 都是"一次 bet" ⇒ 同一个 `range_pct`、同一个 `eq`；**对手最小加注与全下也完全等价**（`update()` 里 allin 直接写成 raise）。金额只影响硬门槛是否翻面 → **这就是 3000 悬崖的机械原因**。

**但金额没被完全丢掉，走了别的链**（核查 4 处）：
