## allin 也受 2000 上限约束（6efac1a）——用户反馈"两对+非锁胜却 allin>2000"

### 根因
「每次下注≤2000，除非牌面≥三条或抢锁赢」此前只约束 raise 的 num，**所有 `{"act":"allin"}` 出口都不检查**：MUST-WIN、SPR 全下、_face_bet 强牌全下、跟全下等。两对+深筹码+SPR低 → allin 金额（=剩余筹码）>2000 无约束。

### 修复（_normalize 层 + 新 helper）
- 新 `_allin_high_bet_allowed(state)`：允许 allin>2000 的例外 = 翻后牌面≥三条 / steal（抢锁赢）/ doomed（本局输即对手锁胜）。**despair 不在主动 allin 例外中**（"弃牌深亏→无条件 allin"只在 fold 升级时生效；主动 allin 仍受限，防两对 allin>2000）。
- 三个出口加超限检查（**仅翻后**——翻前 allin 由「翻前全下分档」eq/盈亏档位控制，不受金额限制，避免误伤 TT 跟全下等）：
  - any_allin 分支（对手全押）：allin 超限且非例外、非 despair → fold；
  - allin 分支（主动全下）：超限 → 降级为 2000 上限加注（min_raise 检查后）；
  - call 分支（跟注即全下）：超限 → fold。
  - despair 时跟全下放行（弃牌会升级 allin，跟全下等价）。

### 验证

- 翻后两对 SPR低主动 allin → 降级 ✓
- 翻后顺子 → allin 放行 ✓；doomed → allin ✓；despair 跟全下 → allin ✓
- 翻前 TT 跟全下 → 分档正常（不受金额限制）✓
