## 【用户实战报告】第10手：跟注即锁赢，但走了便宜跟注

用户贴截图 + 日志片段 + 原话：「第十手跟注输了会导致对手锁赢，此时应该将跟注
改为 allin（如果要跟注的话）」。

### 一、重建与定位（`内容/probe_h10.py`）
实战第10手：河牌我方 J♥Q♣ / 公面 6♥K♥K♦10♠10♥ / 对手 A♦5♠，对手下注 807，
我方**跟注 807**，本手净 −1,614（本场 −2,989 → −4,603），终局以 **1.03BB** 之差落败。

重建后的判定链（数字完全对得上）：
| 判据 | 数值 | 结果 |
|---|---|---|
| 弃牌口径 `lead−2×invested` | −7,592 vs 限 −9,000 | 未 doom（弃牌还能翻身）|
| **跟注口径 `lead−2×exposure`** | **−9,206 ≤ −9,000** | **doom ✓ 跟注即送对手锁赢** |
| `_sealed_by_call`（需再超 15%）| 仅超线 **2.3%** | False → 强制全押不触发 |
| 入口 `_match_adjust` | `normal` | 不拦 |
| 最终输出 | — | **`call`** ← 问题 |

**根因：2026-09-24 重构漏掉的一条。** 旧 `_doom_call_upgrade`（2026-09-14，
用户原话「不给便宜跟注豁免」）被并入 `_endgame_arbitrate`，而该仲裁
**「只往更保守方向修正、不制造新加注/全押」**，唯一能强制全押的
`UA_SEALED_ALLIN` 又要求「明显被锁」（越线 ≥15%）。**第10手只越线 2.3% → 两条路全落空。**

**★注意：这不是计算错误。** 实测该手 `eq=0.339`、需要 `0.250` ——
跟注在**筹码 EV 上是正的**。问题是「这一笔输掉会直接结束比赛」，
属于**政策选择**（薄 +EV 跟注 vs 保住追回线），不是数学必然。

### 二、修复：出口硬规则 `_doom_call_upgrade`（出口最后一步）
- 触发：`_doom_risk(state, include_to_call=True)`；
- **只改写 call**；fold/check/raise 一律不动（所以「宁可弃牌」的判断仍归效用仲裁）；
- 按牌力分流（`_strong_for_big_money`，与规则20 一致）：
  **强牌（翻后 ≥三条 / 翻前 AA..AKs）→ allin（带 lk）；弱牌 → fold**；
- `DOOM_UPGRADE_FORCE_ALLIN`（默认 False）= 无视牌力无条件 allin
  = 用户原话的字面实现。代价：放开规则20 的「主动全押」牌型闸门
  （第21手一对 6 推光 17,226 正是规则20 要防的），故默认不启用；
- 开关 `DOOM_CALL_UPGRADE_ON`（`DBG_NO_DOOM_UPGRADE=1` 关）。
- **搏命区（规则18）与规则2-A 在 decide 入口 return**，不经过本规则 ✓ 不受影响。
