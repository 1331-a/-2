## 规则18/18b 实施：搏命区按牌力分流（commit d3226e2，已推送）

【实现】原 `_gamble_allin` 拆为三件：
  · `_gamble_zone`：`lead < 0 且 lead ≤ −0.95 × 2×追平线`（**去掉「仅翻前」限制** →
    进区即整手在区内，这是「可以慢慢过牌、最后再 all-in」的前提）

    一对且顶对·超对（新 `_pair_is_top`）。全确定性，不用 MC 防抖动。
  · `_gamble_plan`：牌烂 → allin；牌好 → 能过牌就 check / 翻前只需补大盲就 call(溜入) /
    对手加注·下注或河牌免费 → allin(收网)。allin 带 `lk` 标记免检。
  常量新增 `GAMBLE_GOOD_PCT = 0.20`。

  烂牌 9♥4♦：任何街都 allin。均势/领先 → 规则不接管（走正常策略）。
