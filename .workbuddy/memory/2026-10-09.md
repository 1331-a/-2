## ★★ 【用户裁决 + 已实现】按「是否已确保优势」设门（2026-10-09 下午）

用户原话：
> 「是有免费过牌多看不跟，但是看牌的目的是为了确保优势，我都确保优势了还不跟留着干嘛」

**含义（比我原先建议的「整体旁路」更精确）**：`UA_CROSS_CHECK` 的立论基础是
「免费过牌 = 便宜地多看一张牌」，而**「多看一张牌」只有在我们还没成牌时才有价值**；
一旦已经拿到优势牌，过牌就是**把优势闲置** ⇒ 这条硬约束只在**尚未拿到优势牌**时才生效。

### 实现（**已设为默认**）
```python
# strategy.py:230 附近
CROSS_CHECK_STRONG_PASS = True      # env WB_NO_CROSS_STRONG_PASS=1 → 回到旧行为

def _cross_check_exempt(state):     # 放在 _endgame_arbitrate 之前
    # 判定口径与规则10 求稳的「强牌例外」完全一致：
    #   翻后 有效牌型 ≥ 两对（TWO_PAIR）；翻前 超强牌（_is_super_hand）

# _endgame_arbitrate 第①步
if UA_CROSS_CHECK and chip_action.get("act") in ("raise","allin") \
        and not chip_action.get("lk") \
        and not _cross_check_exempt(state):     # ★ 已确保优势 → 不拦
```
